# The Office SQL database
Projet SQL inspiré de la série télévisée *The Office*

## Description
Cette base de données simule la structure d'une entreprise fictive en utilisant SQL. Le projet contient des tables représentant :
- les employés
- les départements
- les clients
- les ventes des employés
- les fournisseurs de succursales

## Technologies utilisées
- SQL
- MySQL

## Ce que j'ai pratiqué
- Création et modification de tables
- Clés primaires et étrangères
- Relations entre tables
- Requêtes SELECT
- JOINs
- Agrégations de données

## Source d'inspiration
Premier pojet réalisé dans le cadre de mon apprentissage du SQL à partir d'un tutoriel YouTube, puis adapté et exploré personnellement.


## Ce que j'ai appris
Ce projet m'a permis de mieux comprendre :
- la structure des bases de données relationnelles
- l'importance des relations entre tables
- comment utiliser les JOINs pour combiner des données
